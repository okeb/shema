ShemaProject — Bible API

Une API ouverte pour explorer la Parole d’Elohim, verset par verset. Obtenez facilement les textes bibliques en JSON pour vos projets web, mobiles ou d’étude.

Voir la documentation Essayer l’API

Pourquoi cette API ?

📖 Accès simple

Récupérez les versets avec une simple requête HTTP. Ex. :
GET /api/v1/verse/Jean/3/16

⚡ Format JSON clair

Chaque réponse contient le texte, la référence et des informations sur le livre pour une intégration rapide.

🌍 Multiversions

Accédez à plusieurs traductions selon les besoins des utilisateurs (Louis Segond, KJV, etc.).
