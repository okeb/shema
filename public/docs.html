Documentation de l'API ShemaProject

Une API REST simple pour accéder aux versets de la Bible.

📋 Format de l'URL

https://www.shemaproject.org/bym/livre/[chapitre/][verset_debut][-verset_fin]

Les éléments entre crochets sont optionnels.

🔬 Testeur d'API en direct

Essayez l'API directement depuis cette page !

💡 Exemples d'utilisation

Exemple 1 : Séquence de versets

Genèse 1:3-7

https://www.shemaproject.org/bym/genèse/1/3-7

Affiche les versets 3 à 7 du chapitre 1 de la Genèse

Voir la réponse 
{
  "Ge. 1:3": {
    "livre": "Ge. ",
    "chapitre": "1",
    "verset": 3,
    "value": "Elohîm dit : Que la lumière apparaisse ! Et la lumière apparut."
  },
  "Ge. 1:4": {
    "livre": "Ge. ",
    "chapitre": "1",
    "verset": 4,
    "value": "Elohîm vit que la lumière était bonne…"
  },
  ...
}

Exemple 2 : Un seul verset

Apocalypse 3:5

https://www.shemaproject.org/bym/ap/3/5

Affiche uniquement le verset 5 du chapitre 3 de l'Apocalypse

Exemple 3 : Chapitre complet

Romains 8

https://www.shemaproject.org/bym/romains/8

Affiche tous les versets du chapitre 8 des Romains

Exemple 4 : Livre complet

Matthieu (tous les chapitres)

https://www.shemaproject.org/bym/matthieu

Affiche tous les versets du livre de Matthieu (chapitres 1 à 28)

📤 Format de réponse

L'API retourne toujours un objet JSON avec les versets demandés :

{
  "Référence": {
    "livre": "Abréviation du livre",
    "chapitre": "Numéro du chapitre",
    "verset": "Numéro du verset",
    "ecrit": "Texte du verset",
    "version": "Nom de la version biblique"
  }
}

Texte original

/orig sert le WLC hébreu/araméen pour l'Ancien Testament et le Textus Receptus Scrivener 1894 grec pour le Nouveau Testament.

GET /orig/jean/3/16?mode=interlinear&translit=1

mode=orig est le mode par défaut. mode=interlinear ajoute les gloses françaises et translit=1 la translittération et la phonétique. Les segments Strong's sont toujours présents pour cette version.
